
# Hobikusports.id

Starsport.id adalah toko online perlengkapan olahraga berbasis website dengan desain mobile-first.

## Tentang Project
Website ini dikembangkan menggunakan Next.js, TypeScript, dan Tailwind CSS.

## Fitur yang Direncanakan
- Homepage toko olahraga
- Katalog dan pencarian produk
- Kategori produk
- Detail produk
- Keranjang belanja
- Checkout melalui WhatsApp
- Pengelolaan produk

## Status
Dalam tahap pengembangan.

## Teknologi
- Next.js
- TypeScript
- Tailwind CSS
- GitHub Codespaces
